# Instrumento de investigación de usuarios
## Proyecto: SmartBills Cleaner

## 1. Propósito del instrumento

Este instrumento está diseñado para apoyar la investigación de usuarios del proyecto **SmartBills Cleaner**, una aplicación orientada a la carga, organización, validación y consulta de facturas digitales. Su objetivo es conocer cómo los potenciales usuarios gestionan actualmente sus facturas, qué dificultades experimentan, qué expectativas tienen frente a una solución inteligente y qué criterios de usabilidad consideran importantes en una interfaz de este tipo.

Aunque la actividad solicita entrevistas, este documento está construido como una **encuesta guiada / entrevista semiestructurada**, de modo que sirva tanto para recolectar respuestas comparables entre participantes como para profundizar en comentarios durante la conversación.

## 2. Perfil de participantes esperado

Se recomienda aplicar este instrumento a cuatro participantes:

- 1 usuario novato o con poca experiencia en herramientas digitales de gestión documental.
- 1 usuario intermedio.
- 1 usuario avanzado o con experiencia frecuente en manejo de facturas, archivos o sistemas administrativos.
- 1 usuario adicional que permita contrastar comportamientos, necesidades o dolores comunes.

## 3. Introducción para leer al participante

Hola, gracias por participar en esta entrevista. Estoy desarrollando una propuesta de aplicación llamada **SmartBills Cleaner**, enfocada en facilitar la carga, revisión y consulta de facturas digitales. El propósito de esta conversación es conocer cómo gestionas actualmente este tipo de documentos, qué problemas enfrentas y qué elementos valorarías en una interfaz de este tipo. La información será usada únicamente con fines académicos y de diseño del prototipo. Tus respuestas son confidenciales y puedes omitir cualquier pregunta si así lo deseas.

## 6. Preguntas de contexto y comportamiento actual

1. ¿Cómo gestionas actualmente tus facturas o documentos similares?
2. ¿Dónde sueles almacenarlos: correo, carpetas del computador, nube, WhatsApp, impresos u otro medio?
3. Cuando necesitas buscar una factura específica, ¿cómo lo haces normalmente?
4. ¿Qué dificultades encuentras al momento de organizar o recuperar este tipo de documentos?
5. ¿Te ha pasado que pierdes tiempo validando datos como proveedor, fecha, valor o número de factura?
6. ¿Qué tan importante es para ti tener un sistema que permita revisar o corregir datos automáticamente extraídos de un documento?

## 7. Preguntas sobre necesidades y expectativas

1. Si existiera una aplicación que permitiera subir facturas y extraer automáticamente sus datos, ¿qué esperarías que hiciera bien?
2. ¿Qué información considerarías esencial ver apenas ingresas a una aplicación de este tipo?
3. ¿Te resultaría útil contar con un historial o listado filtrable de facturas? ¿Por qué?
4. ¿Te generaría confianza poder revisar y editar los datos extraídos antes de guardarlos?
5. ¿Qué tan útil sería para ti consultar tus facturas con preguntas en lenguaje natural, por ejemplo: “¿cuánto gasté este mes?” o “muéstrame las facturas de energía”?
6. ¿Qué temores o dudas tendrías al usar una herramienta inteligente para gestionar documentos?

## 8. Preguntas enfocadas en usabilidad e interacción

1. Cuando usas una aplicación nueva, ¿qué hace que te parezca fácil o difícil de usar?
2. ¿Prefieres interfaces simples con pocas opciones visibles o paneles más completos con más información? ¿Por qué?
3. ¿Qué tan importante es para ti recibir retroalimentación del sistema mientras un documento se está procesando?
4. ¿Qué elementos de una interfaz te ayudan a sentir control y confianza al realizar una tarea?
5. Si tuvieras que corregir manualmente datos de una factura, ¿cómo te gustaría que estuviera organizada esa pantalla?
6. ¿Qué errores consideras que una aplicación así debería prevenir desde la interfaz?

## 9. Preguntas diferenciales según nivel de experiencia

### Para usuario novato

1. ¿Qué parte de una aplicación de este tipo crees que podría confundirte más?
2. ¿Qué ayudas visuales o mensajes te facilitarían completar una tarea?
3. ¿Preferirías un flujo paso a paso o una interfaz completa desde el inicio?

### Para usuario avanzado

1. ¿Qué funciones adicionales esperarías de una aplicación de gestión documental inteligente?
2. ¿Qué tan importante es para ti filtrar, clasificar o consultar documentos de forma rápida?
3. ¿Qué automatizaciones considerarías realmente valiosas para ahorrar tiempo?

## 10. Preguntas de validación del concepto SmartBills Cleaner

1. En una escala de 1 a 5, ¿qué tan útil te parece una aplicación como SmartBills Cleaner?
2. En una escala de 1 a 5, ¿qué tan fácil imaginas que debería ser su uso?
3. ¿Cuál consideras que sería la funcionalidad más valiosa del sistema?
4. ¿Cuál crees que sería el principal riesgo o limitación?
5. Si pudieras pedir una mejora desde el inicio, ¿cuál sería?

## 11. Cierre de la entrevista

1. ¿Hay algo más que quieras agregar sobre cómo debería funcionar una herramienta de este tipo?
2. ¿Te sentirías dispuesto a probar un prototipo inicial de la aplicación en una siguiente fase?

## 13. Cómo usar este instrumento en la actividad

Este documento puede emplearse como evidencia de la **guía de entrevista diligenciada**. La sugerencia de aplicación es la siguiente:

- Duración estimada por participante: 15 a 20 minutos.
- Modalidad: virtual o presencial.
- Registro: video, audio o notas.
- Resultado esperado: insumos para construir el diagrama de afinidad, identificar patrones de comportamiento y definir al menos dos user personas.

## 14. Nota metodológica breve para el informe

El instrumento fue diseñado con un enfoque semiestructurado para permitir comparabilidad entre respuestas sin perder riqueza cualitativa. Las preguntas cubren contexto de uso, comportamiento actual, necesidades, expectativas y criterios de usabilidad, con el fin de relacionar los hallazgos tanto con la definición del problema como con el diseño progresivo del prototipo de interfaz.
