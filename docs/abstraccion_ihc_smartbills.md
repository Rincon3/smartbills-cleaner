# SmartBills Cleaner: abstracción del concepto y estado actual del prototipo

SmartBills Cleaner es una propuesta de aplicación inteligente orientada a la gestión y análisis de facturas digitales. La idea central del sistema es facilitar a los usuarios la carga, organización, validación y consulta de documentos contables mediante una interfaz web que combine automatización documental con componentes de inteligencia artificial. El problema que se busca atender es la dificultad de administrar grandes volúmenes de facturas de forma manual, especialmente cuando se requiere localizar información específica, revisar errores de digitación o consolidar datos para consulta posterior.

Desde el punto de vista conceptual, la aplicación se apoya en varios elementos que le dan valor funcional. El primero es el procesamiento documental, entendido como la capacidad de recibir archivos como PDF o imágenes y extraer de ellos datos relevantes. El segundo es la gestión estructurada de la información, ya que cada factura debe quedar asociada a un usuario, un estado de procesamiento y un conjunto de metadatos consultables. El tercero es el uso de inteligencia artificial para ampliar la interacción con el sistema, especialmente mediante consultas en lenguaje natural sobre la información contenida en los documentos. Aunque este último componente aún se encuentra en una etapa inicial, forma parte del enfoque general de la solución y orienta tanto la arquitectura como el diseño de las interfaces.

En relación con las interfaces de usuario, el proyecto toma como referencia aplicaciones de gestión documental, paneles administrativos y sistemas de consulta asistida. De estas referencias se retoman patrones comunes de interacción como el inicio de sesión, la navegación por panel lateral, los tableros con indicadores, los formularios de carga de archivos, los listados filtrables y las vistas de detalle para revisar información extraída. Estos patrones son relevantes para la materia de Interacción Humano-Computador porque permiten construir una experiencia más familiar, predecible y eficiente para el usuario, reduciendo la carga cognitiva y favoreciendo el aprendizaje del sistema.

Hasta el momento, el desarrollo ha permitido construir una primera versión funcional del prototipo. Actualmente se cuenta con pantallas de inicio de sesión, dashboard principal, carga de facturas, listado de documentos, gestión de usuarios y panel de auditoría. En el flujo actual, el usuario puede autenticarse, acceder a un panel con métricas básicas, subir una factura y visualizar los datos detectados por el sistema. También existe una vista para revisar y editar la información extraída, así como módulos administrativos para control de usuarios y trazabilidad de acciones. En esta etapa, algunas funciones avanzadas se encuentran simuladas, como parte del procesamiento OCR y de ciertas integraciones inteligentes, pero ya existe una base funcional que permite validar la propuesta de interacción.

Desde la perspectiva de usabilidad, el prototipo busca responder a principios fundamentales como claridad, consistencia, visibilidad del estado del sistema y control por parte del usuario. La organización de la interfaz se ha pensado para que el usuario identifique rápidamente dónde se encuentra y qué acciones puede realizar. El dashboard resume el estado general del sistema, la carga documental prioriza una interacción simple mediante selección o arrastre de archivos, y el módulo de validación busca dar confianza al usuario al permitir revisar y corregir datos antes de continuar. Asimismo, la separación entre funciones operativas y administrativas contribuye a una mejor comprensión del sistema según el perfil de uso.

Como prototipo en evolución, el proyecto todavía presenta oportunidades de mejora en términos de interacción. Entre ellas se destacan el fortalecimiento del flujo de retroalimentación al usuario durante el procesamiento, la consolidación del módulo de consultas en lenguaje natural y la profundización de mecanismos de ayuda, confirmación y prevención de errores. Sin embargo, el estado actual ya permite observar una propuesta coherente entre problema, arquitectura funcional e interfaz de usuario, lo que constituye una base adecuada para continuar con el refinamiento del sistema desde una perspectiva de experiencia de usuario y usabilidad.
